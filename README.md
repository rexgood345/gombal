# 💕 Gombal Bucin Lucu

Website gombal bucin lucu dengan bunga-bunga animasi, responsive, dan siap di-deploy ke GitHub Pages.

## 🌸 Fitur
- 20+ gombal bucin lucu & random
- Bunga-bunga melayang animasi di background
- Tombol **Kirim ke Doi** — share langsung atau salin ke clipboard
- Responsive di HP maupun desktop
- Desain glassmorphism yang cute

## 🚀 Deploy ke GitHub Pages

1. **Buat repository baru** di GitHub (misal: `gombal-bucin`)
2. Upload semua file (`index.html`, `style.css`, `script.js`)
3. Masuk ke **Settings → Pages**
4. Di bagian **Source**, pilih branch `main` → folder `/ (root)` → klik **Save**
5. Tunggu beberapa menit, lalu akses di:
   ```
   https://<username>.github.io/<nama-repo>/
   ```
